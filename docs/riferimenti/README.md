# Riferimenti visivi

Screenshot dell'app WeMeet (iPhone, 5 agosto 2026, 1179×2556 @3x). Sono la
fonte da cui è misurato `docs/design.md`.

| File | Cosa mostra |
|---|---|
| `app-01-avvio.png` | Schermata di lancio: fondo quasi nero, marchio bianco, tag rosso |
| `app-02-home.png` | Home: fondo sabbia, chip di periodo, card raggruppate per giorno |
| `app-03-home-espansa.png` | Stessa home con una categoria espansa: la card di evento sta *dentro* quella di categoria |
| `app-04-scopri.png` | Ricerca: campo a pastiglia, filtri, cerchi di categoria, card ricche |
| `app-05-dettaglio-evento.png` | Dettaglio: foto a tutto schermo, card che risale, barra d'azione fissa |

**I volti dei partecipanti sono stati sfocati.** Erano fotografie di profilo di
persone reali; questo repository è collegato dal business case e potrebbe
diventare pubblico. La sfocatura tocca solo le fasce degli avatar: geometria,
colori e struttura restano leggibili, ed erano l'unica cosa che ci serviva.

Le fotografie degli eventi sono di WeRoad e restano tali: servono a leggere il
trattamento visivo, non a essere riusate (vedi `design.md` §9).
